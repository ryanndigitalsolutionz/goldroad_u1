# GoldRoad U1

## Project 2 — Full Stack Freelance Marketplace

GoldRoad U1 is a freelance and marketplace platform designed to connect clients, freelancers, businesses, entrepreneurs, and customers through a simple system for offering, discovering, proposing, and purchasing quality goods and services.

> **The quality platform worth investing in.**

---

## Project 2 Goal

This version of GoldRoad U1 focuses on the core freelance marketplace experience.

Users can register as either:

- **Clients** — people who need work completed and post projects.
- **Freelancers** — people who offer their skills and submit proposals to projects.

Both roles interact with the same marketplace and shared project data.

---

### Client
